# phi-shell

Desktop shell, QML on Quickshell 0.3.1. Master plan §8.

## Running it

Quickshell finds a config by folder name under `~/.config/quickshell/`, so
clone this repository to exactly `~/.config/quickshell/phi`:

```
git clone https://github.com/phiOS-git/phi-shell.git ~/.config/quickshell/phi
```

`Config/Tokens.qml` is generated by `phi theme` (design/adapters.txt in
phios-dotfiles) and is gitignored — a fresh clone does not have it yet.
Render it once before the first run:

```
phi theme set dark
```

`phi theme set` renders every themed target on the machine, not only this
one; that is expected and safe to run repeatedly. Then:

```
qs -p ~/.config/quickshell/phi
```

Quickshell hot-reloads on save; a broken `Config/Tokens.qml` shows the same
way as any other QML file — as a QML error in this terminal, not a crash.

See `docs/tokens-example.md` for the shape of the generated file without
running `phi theme set` first.
